# 🧮 Projeto MYCALC_

Este é um projeto simples de calculadora desenvolvido em Python, estruturado com Git usando branches separadas para cada operação matemática básica:

- Soma
- Subtração
- Multiplicação
- Divisão

---

## 🚀 Funcionalidades

- Solicita dois números do usuário
- Permite escolher a operação desejada
- Exibe o resultado da operação

---

## 🛠️ Estrutura do Repositório

Cada operação foi desenvolvida em sua própria branch:

| Branch         | Função                      |
|----------------|-----------------------------|
| `main`         | Calculadora completa         |
| `soma`         | Operação de adição           |
| `subtracao`    | Operação de subtração        |
| `multiplicacao`| Operação de multiplicação    |
| `divisao`      | Operação de divisão          |

---

## 📦 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/calculadora-python.git
   cd calculadora-python
2. Execute o script principal na branch main:
   ```bash
   python calculadora.py
3. O programa pedirá para o usuário escolher a operação e inserir dois números.
